# Detective Mystery

**Detective Mystery** е 3D детективска игра от първо лице за Windows, която правим с Unity и C#. В нея влизаш в ролята на детектив, който разследва престъпление от своя офис, преглежда материали и сам стига до извод кой е извършителят и защо го е направил. Играта е за хора, които обичат мистерии, логически задачи и внимание към детайлите.

## MVP обхват

### MUST HAVE (задължителни функционалности)

| Функционалност | Описание |
| --- | --- |
| Начало на играта | Стартиране на разследване от начално меню. |
| Детективска стая | Основна 3D стая, в която играчът се движи и работи с предметите. |
| Компютър | Преглед на файлове, съобщения, снимки и други материали по случая. |
| Събиране и преглед на улики | Откриване и четене на документи и доказателства. |
| Заподозрени | До 5 заподозрени в един случай. |
| Заключение за извършителя и мотива | Играчът решава кой е виновен и какъв е мотивът му. |

### NICE TO HAVE (допълнителни функционалности)

| Функционалност | Описание |
| --- | --- |
| Съдебна система | Представяне на доказателствата пред съд след разследването. |
| Разширена детективска дъска | Свободно подреждане, бележки и свързване на улики. |
| Разширени функции на телефона | Допълнителни обаждания, съобщения и информация от телефона. |
| Допълнителни случаи | Нови истории и престъпления за разследване. |

Подробното MVP описание се намира в [docs/MVP.md](docs/MVP.md).

## Стартиране на проекта

### Изисквания

- Компютър с Windows
- Unity Hub и Unity Editor `6000.6.3f1`
- Visual Studio (ако ще се редактира кодът)

### Стъпки за стартиране

1. Изтеглете или клонирайте хранилището от GitHub.
2. Отворете Unity Hub и добавете основната папка на проекта (**Add** / **Open**).
3. Отворете проекта с Unity `6000.6.3f1`.
4. Отворете сцената `Assets/_Game/Scenes/DetectiveOffice.unity`.
5. Натиснете **Play** в Unity Editor.

### Забележки

Проектът има и готов Windows билд (`build/DetectiveGame.exe`), който може да се ползва за демонстрация директно на Windows, ако не се пуска през Unity Editor.

## Структура на проекта

- `Assets/_Game/Scenes/` — сцените в играта (`DetectiveOffice.unity`).
- `Assets/_Game/Scripts/` — C# кодът на играта (движение, компютър, телефон, дъска, документи).
- `Packages/` — използваните Unity пакети.
- `ProjectSettings/` — настройките на Unity проекта.
- `docs/` — документацията и снимките от играта.
