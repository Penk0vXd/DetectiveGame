# DetectiveGame

Оригинална 3D first-person detective / murder-mystery игра, разработвана с Unity и C#.

## Текуща фаза

Detective Office Prototype.

Прототипът проверява movement и interaction във физически detective office с computer, phone, documents, case files и evidence board. Това все още не е завършен murder case.
