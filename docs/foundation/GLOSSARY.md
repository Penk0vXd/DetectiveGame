# Canonical glossary

**Status:** активна терминология.

| Термин | Значение | Не го бъркай с |
|---|---|---|
| **Source** | Произход на информация: човек, документ, снимка, report, object | Самата информация |
| **Observation** | Това, което играчът директно възприема или записва | Гарантирана обективна истина |
| **Fact** | Тясно формулирана информация, подкрепена от source с определена reliability | Извод какво доказва |
| **Statement / Claim** | Какво човек твърди | Objective truth |
| **Evidence item** | Source или записан факт, запазен за investigation | Proof за едно conclusion |
| **Interpretation / Inference** | Заключение от facts/claims | Raw evidence |
| **Contradiction** | Данни, които не могат едновременно да са верни при същите assumptions | Автоматично доказателство за лъжа/вина |
| **Lead** | Възможна посока за investigation | Mandatory quest objective |
| **Event** | Нещо известно или предполагаемо случило се във време/място със source и confidence | Напълно потвърдена timeline truth |
| **Case truth** | Author-defined objective state на case-а | Player knowledge |
| **Player knowledge** | Откритата или записана от играча информация | Всички case facts |
| **Red herring** | Правдоподобна информация, подкрепяща грешен/непълен извод | Произволен шум |
| **Deduction** | Player-formed relationship или conclusion | Automatic clue completion |
| **Accusation** | Формално подадено заключение | Временна theory |
| **Prototype code** | Код за тестване на въпрос с ограничен scope | Автоматично production architecture |
| **Production direction** | Предвидена устойчива посока | Доказателство, че вече е implemented |
