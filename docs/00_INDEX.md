## Статуси

- **IMPLEMENTED:** доказано в текущото repository.
- **DECIDED:** одобрена посока.
- **VALIDATED:** успешно проверено срещу explicit criteria.
- **PROPOSED:** кандидат, не е одобрен.
- **OPEN QUESTION:** изисква решение.
- **NEEDS RESEARCH:** изисква evidence.
- **DEFERRED:** умишлено за по-късно.
- **REJECTED:** изрично изключено.
- **REVISIT:** отново отворено решение.
