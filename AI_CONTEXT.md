# Универсална AI входна точка

Това repository поддържа всеки AI модел чрез model-neutral instruction chain.

Зареди в този ред:

1. `AGENTS.md` — задължителни правила
2. `docs/00_INDEX.md` — context router
3. `docs/foundation/DECISIONS.md` — одобрена product истина
4. `docs/foundation/OPEN_QUESTIONS.md` — нерешени избори
5. task-specific design/technical/prototype документи
6. реалните repository файлове, засегнати от задачата

Не приемай, че proposal е одобрен или че документация доказва runtime поведение. За standalone system prompt използвай `docs/ai/MASTER_SYSTEM_PROMPT.md`, а за specialist role — `docs/ai/ROLE_PROMPTS.md`.
